# Truck-Simulator-Logistics-Game
Mini Project that simulates a truck company that delivers products to destinations. The application mainly focuses on the logistics side in terms of keeping track of money, products, and trucks

#Notes:

Project was designed as a way to practice encapsulation of data, using data structures, and learn the basics of PyQt5 for simple GUI.
Use of generative A.I. such as chatGpt was used for learning about PyQt5's scene designs, widgets, as well as fnding examples and use cases on how to create and use scenes. Code from A.I. was experimented with in order to design and create a graphic user interface for specific scenes that is organized and functions as intended.
